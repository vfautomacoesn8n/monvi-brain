# Registro de exceções de conectividade do Monvi Brain v1

## Regra

Uma exceção só é válida quando o isolamento é intencional, justificável e aprovado.

## Categorias permitidas

- RAW;
- histórico;
- archived;
- deprecated;
- evidence isolada por segurança;
- output técnico sem navegação humana;
- arquivo raiz;
- exceção aprovada.
