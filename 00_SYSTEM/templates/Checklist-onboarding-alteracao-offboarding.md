# Checklist de onboarding, alteração e offboarding

## Onboarding

- [ ] identidade criada;
- [ ] função registrada;
- [ ] gestor definido;
- [ ] clientes atribuídos;
- [ ] projetos atribuídos;
- [ ] permissões aprovadas;
- [ ] espaço individual criado;
- [ ] Helpper individual configurado;
- [ ] skills atribuídas;
- [ ] ferramentas atribuídas;
- [ ] repositórios atribuídos;
- [ ] validade definida;
- [ ] MFA configurado;
- [ ] acesso testado;
- [ ] log registrado.

## Alteração de função

- [ ] papel anterior revisado;
- [ ] permissões antigas removidas;
- [ ] novas permissões aprovadas;
- [ ] clientes revisados;
- [ ] projetos revisados;
- [ ] skills revisadas;
- [ ] ferramentas revisadas;
- [ ] repositórios revisados;
- [ ] memória revisada;
- [ ] Helpper atualizado;
- [ ] acesso testado;
- [ ] log registrado.

## Offboarding

- [ ] identidade suspensa;
- [ ] sessões revogadas;
- [ ] Helpper desabilitado;
- [ ] ferramentas revogadas;
- [ ] repositórios revogados;
- [ ] projetos transferidos;
- [ ] clientes removidos;
- [ ] memória bloqueada;
- [ ] histórico preservado;
- [ ] dados locais revisados;
- [ ] responsável pela transição definido;
- [ ] log registrado;
- [ ] encerramento confirmado.
