O Helpper Filipe poderá consultar bibliotecas gerais autorizadas, mas não poderá alterar, promover ou publicar conteúdo nelas automaticamente.

Bibliotecas de cliente e projeto permanecem escopos separados e exigem autorização própria.

## Relação com o Helpper

O Helpper Filipe poderá:

- consultar conteúdo autorizado desta biblioteca;
- organizar referências e notas;

- identificar conflitos ou conteúdo desatualizado;
- sugerir classificação;
- propor promoção de conhecimento.

O Helpper Filipe não poderá:

- acessar a biblioteca pessoal de Victor;

- ativar memória técnica persistente.

`captured → classified → proposed → reviewed → approved → published`

A promoção exigirá revisão humana, sanitização, classificação, verificação de dados pessoais, verificação de dados de clientes e definição de owner institucional.
