## Regras

- todo projeto deve estar vinculado a exatamente um cliente autorizado;
- nenhum projeto real deve ser criado sem autorização humana;
- `active_client` e `active_project` devem ser explícitos;
- dados de clientes diferentes não podem ser misturados;
- secrets permanecem fora do Monvi Brain;
- a estrutura desta pasta não comprova execução ou aceite.
