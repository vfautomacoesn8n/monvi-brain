## Escopo e jurídico

- [ ] escopo ou proposta aplicável identificado;
- [ ] autorização necessária registrada;
- [ ] aceite necessário registrado;
- [ ] uso de marca, conteúdo e ativos autorizado;
- [ ] promessa comercial compatível com o que será entregue;
- [ ] dependências de terceiros registradas;
- [ ] item que exige revisão jurídica foi escalado;
- [ ] nenhuma cláusula ou obrigação foi presumida.

## LGPD e privacidade

- [ ] finalidade do tratamento registrada;
- [ ] dados coletados são minimizados;
- [ ] base legal foi validada por responsável competente quando aplicável;
- [ ] transparência necessária foi prevista;
- [ ] compartilhamentos foram mapeados;
- [ ] retenção foi definida ou marcada como pendente;
- [ ] dados sensíveis receberam avaliação específica;
- [ ] fornecedores e transferências foram avaliados conforme o risco;
- [ ] procedimento para solicitações de titular foi considerado quando aplicável;
- [ ] incidentes de privacidade estão tratados ou formalmente bloqueados.

## Segurança

- [ ] acessos possuem responsável;
- [ ] princípio do privilégio mínimo foi aplicado;
- [ ] credenciais não estão expostas;
- [ ] segredos não estão em código ou documento aberto;
- [ ] ambiente está identificado;
- [ ] autenticação forte foi considerada quando aplicável;
- [ ] backup foi verificado quando aplicável;
- [ ] rollback foi definido quando aplicável;
- [ ] fornecedor crítico foi avaliado;
- [ ] incidentes abertos possuem contenção e responsável;
- [ ] monitoramento inicial foi considerado.
